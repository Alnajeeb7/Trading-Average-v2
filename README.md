## ✨ Features

- **Live Market Price Tracking** — Enter current stock prices to see real-time P&L
- **Transaction Management** — Record buy transactions with quantity and price
- **Automatic Calculations** — Instantly computes average buy price, total invested, and market value
- **Recovery Plans** — Choose from Aggressive, Balanced, Conservative, or set a Manual target
- **Projections** — See expected outcomes: final shares, new average price, required rise %, and net profit
- **Dark/Light Mode** — Toggle between themes for comfortable viewing
- **Data Persistence** — Your data stays saved in localStorage until you press reset
- **Responsive Design** — Works perfectly on mobile and desktop
- **Educational Tool** — Understand P&L concepts with built-in guide cards

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Alnajeeb7/Trading-Average-v2.git
cd Trading-Average-v2

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```

---

## 📱 Usage Guide

1. **Enter Live Market Price** — Input the current market price of your stock
2. **Add Transactions** — Enter quantity and buy price for each purchase
3. **View Dashboard** — See your Avg Buy Price, Total Shares, Total Invested, and Market Value
4. **Choose Recovery Plan** — If in loss, select a strategy to recover
5. **Review Projection** — See how buying more shares affects your average
